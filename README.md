# Drawpad
It uses arduino, can be locked with your custom pass, and stores your precious drawings. :)

## Materials
- Arduino Uno
- Tft Lcd Screen
  
- You need an external source of at least 5 volts to power the system.
  
## Documentation/Process
 All you do is stack the tft screen onto the arduino uno.
